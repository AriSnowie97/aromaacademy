Покладіть сюди відеофайли (.mp4, .webm, .mov) для Арома-роликів, наприклад:
- 1.mp4 (або clip_1.mp4) -> автоматично прив'яжеться до Арома-ролика 1 (урок 1.1)
- 3.mp4 (або clip_3.mp4) -> ролик 3 (урок 3.1)
Або завантажте відео прямо через адмін-панель у застосунку (вкладка «Адмін Наталії» -> Арома-ролики).
